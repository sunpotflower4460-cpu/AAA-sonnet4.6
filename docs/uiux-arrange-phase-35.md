# Phase 5 Arrange Report

## 目的

MVPのUI/UXを、残心らしい静けさ・余白・現代和の方向へ磨き込み、体験を最大化する。

---

## 改善した内容

- **ヘッダー刷新** — 「残心」を38pxの大きな明朝体に。上部の余白を55pxに広げ、「Zanshin Notes」をスモールキャップ風に配置。タグラインをイタリック体で静かに添える。
- **メモカードのスタガードアニメーション** — カードが一枚ずつ順番にfade+slide-upで現れる（50msずつオフセット）。
- **メモカードの洗練** — 左の刀線アクセントをお気に入りで3px・通常2pxに変更。ホバー時の枠線を自然に濃くする。影を最小限に。
- **エディタの余白拡大** — 横パディング26px、上パディング42px、下パディング55pxへ。本文の行間を1.85に拡大（より書く呼吸ができる）。
- **タイトル入力の強化** — フォントサイズを24px・文字間隔を微調整・プレースホルダー透明度を40%に落として邪魔にならないように。
- **自動保存表示の刷新** — 11pxのごく小さなテキスト、文字間隔を広めにして「気配」程度の存在感に。
- **戻るボタンの改善** — ← と文字を隙間6pxで分離。13px・文字間隔0.02emで静かに読める。
- **お気に入りボタンのアニメーション** — ON時にscale(1.1)で微細な「ふっ」と感。
- **削除ボタンの透明度** — opacity 0.65で存在は見えるが主張しない。
- **EmptyState のアニメーション** — `animate-fade-slide-up` でページ全体が静かに現れる。円相（Ensō）がゆっくり呼吸するアニメーション（5秒サイクル）。
- **SearchBarの洗練** — py-10px・文字間隔0.01emで入力欄をより広くなめらかに。フォーカス時のトランジションを300msに。
- **CSS強化**:
  - `body` に radial-gradient の大気感（金と藍の微光）
  - `caret-color: var(--color-indigo)` でカーソルが藍色
  - `::selection` の背景を藍12%で落ち着いた選択感
  - スクロールバーを3px極細・半透明に
  - `@keyframes fadeSlideUp` / `breathe` / `fadeIn` 定義
  - `--ease-soft` カスタムイージング
  - スタガードディレイ用クラス `.card-delay-0` ～ `.card-delay-9`
- **ZanshinMark に `animate` prop 追加** — 呼吸アニメーションの切り替えを可能に。

## デザイン判断

### ヘッダー
「残心」という言葉が画面に入った瞬間に静かな印象を与えるために、38pxという大きさを選んだ。小さな文字では「ただのタイトル」になってしまう。上に55pxの余白を取ることで、iPhoneで持ったとき上部に「間（ま）」が生まれる。

### カードアニメーション
一枚ずつ50msずらしてフェードインすることで、メモ一枚一枚の存在感が生まれる。一気に全部現れるより、「言葉が置かれていく」感覚を演出した。

### エディタの行間1.85
ゴールデンレシオ（1.618）より少し大きい1.85を選んだのは、書いている最中の「呼吸」を意識したから。文字と文字の間に空気が通るような行間にした。

### 大気感（background gradient）
RGB値の金と藍を極めて薄くbodyに乗せることで、画面全体が均質な和紙ではなく、微妙に「陽の当たる和室」の光の変化を感じさせる。過剰にならない範囲で留めた。

### 呼吸するEnso
空状態の円相が静かに拡縮することで、アプリが「死んでいない」ことを伝える。5秒サイクルは、人間の呼吸に近いテンポ。
